Política de Privacidade

Última atualização: 12 de novembro de 2026

1. Quem somos

“Pista Fria” é um projeto pessoal de criação de vídeos sobre histórias reais. O aplicativo “Pista Fria” é uma ferramenta de automação usada exclusivamente pelo próprio dono do canal para publicar os seus vídeos no YouTube.

2. Uso dos Serviços de API do YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao usar o aplicativo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google é regido pela Política de Privacidade do Google.

3. Quais dados acessamos

O aplicativo solicita apenas a permissão de enviar vídeos (escopo youtube.upload) para o canal do próprio dono do projeto. Ele não lê, não coleta e não armazena dados pessoais de espectadores ou de qualquer outro usuário.

4. Como usamos os dados

A autorização concedida é usada somente para publicar, no canal do dono do projeto, os vídeos produzidos por ele. Nenhuma informação é vendida, compartilhada com terceiros ou usada para publicidade.

5. Armazenamento

As credenciais de acesso ficam guardadas de forma criptografada, em ambiente privado acessível apenas ao dono do projeto. Não mantemos bancos de dados com informações de usuários.

6. Como revogar o acesso

O acesso pode ser revogado a qualquer momento na página de permissões da Conta Google.

7. Contato

Dúvidas sobre esta política podem ser enviadas pelos comentários ou mensagens do canal @br.pistafria no YouTube.
